## 3. 关键观察

1. **只有 A2 有真实运行时 E1/E2**：默认口令 `admin:`（空口令）返回 200，`/home.asp` 管理页 38,782 字节；未认证 HNAP 200。故 A2 拒绝，且 `conf=0.900`。
2. **A2 的静态版本仍只是 conditional**：`A2_static` 为 U=0.901 / A=0.042 / conf=0.300；说明“E3 到 E1”的证据升级直接改变了判定，这正是本项目要证明的价值。
3. **R3 规则修正后没有有效 E3**：U=1.000、A=0.000、conf=0.000，全部检查项 `not_tested`；不能把“扫描没报”当成 `clear` 或 pass。
4. **C1–C4 是 D-Link 相机替换后的 Tapo**：原 D-Link 多版本无 rootfs，失败记录保留在 `materials/firmae/unpack_C*_dlink_fail.json`；不把失败样本计入成功。
5. 12 个固件中 **11 个没有运行时 E1/E2**，因此大部分只能是 conditional；这不是判定器“故意从严”，而是证据不足。
6. 阈值尚未用锚点集校准；上述数字只用于初赛样例，不写成最终准确率。
7. **2026-11-22 规则修正**：`src/evidence.py` 增加标准 URL 白名单、HTML 帮助链接过滤、运行时口令/工厂测试标记排除；旧判定值（A1 U=0.625 等）已作废，以本表为准。

## 4. 复现命令

```bash
# 单台（以 R1 为例）
python -m src.exposure materials/firmae/evidence_sample_R1.json \
  --firmware-id R1 --output materials/decisions/R1.json

# A2 运行时（E1/E2）
python -m src.exposure materials/evidence_runtime_dcs.json \
  --firmware-id A2 --output materials/decisions/A2.json

# A2 静态对照（E3-only）
python -m src.exposure materials/evidence_sample_a2.json \
  --firmware-id A2 --output materials/decisions/A2_static.json
```
