## 2. 王同学（A）怎么做

### 2.1 你的文件已经预填

王同学打开：

```powershell
code materials\annotations\annotator_A.json
code materials\annotations\evidence_audit.md
```

`annotator_A.json` 里已经是：

- `found`：有对应 evidence；
- `not_tested`：没有 evidence、也没有实测；
- 没有 `clear`。

你的任务不是从零猜，而是**逐条核对**。

### 2.2 逐台核对（12 台）

顺序：

```text
A1 → A2 → A3 → A3-19 → R1 → R2 → R3 → C1 → C2 → C3 → C4 → C5
```

每台 9 格，核对方法：

1. 在 `evidence_audit.md` 找到该固件；
2. 看该行的 `证据 ID` 和 `raw_ref`；
3. 打开对应 evidence 文件，确认这条证据真的存在；
4. `found` 对得上 → 保留；
5. 对不上 → 改成正确值；
6. `not_tested` 不要随手改成 `clear`。

### 2.3 王同学的自查

```powershell
python -c "import json; d=json.load(open(r'materials\annotations\annotator_A.json', encoding='utf-8')); a=d['annotators']['A']; print('TODO=', sum(v=='TODO' for f in a.values() for v in f.values()))"
```

必须是 `TODO= 0`。

### 3.2 每台 9 格，按这个规则填

对每个固件 × 每个检查项：

1. evidence 里有这个 `check_code` → 填 `"found"`；

## 4. 例子（照着理解，不要照抄）

### 例 1：A1 `CRED_DEFAULT_SERVICE_LOGIN` → `found`

- 审计行：`A1 | CRED_DEFAULT_SERVICE_LOGIN | found | ... | E-A1-0002 | etc_ro/passwd:1`
- 打开 `materials/evidence_sample_a1.json`，搜索 `E-A1-0002`；
- 证据是 root 可登录账号（E3 静态）；
- 填 `"found"`，理由写“E3 静态发现可登录账号”。

> 注意：E3 是静态发现，不是 E1；`found` 不等于“已验证可利用”。

### 例 2：A2 `CRED_DEFAULT_ADMIN_WEB` → `found`（E1）

- 证据：`E-A2-E1-0001`；
- `raw_ref = materials/firmae/dcs_login_home_headers.txt:1`；
- 实际请求：`admin:` 空口令返回 200，`/home.asp` 返回 38,782 字节；
- 填 `"found"`，理由写“E1 默认口令实测”。

这是 12 台里唯一的真实 E1，A2 因此是 `reject`。

### 例 3：A2 `UNAUTH_MGMT_ENDPOINT` → `found`（E2）

- 证据：`E-A2-E2-0001`；
- 未认证 `GET /HNAP1/` 返回 200 + `GetDeviceSettingsResponse`；
- 填 `"found"`，理由写“E2 单次未授权请求”。

### 例 4：A3 `EGRESS_PLAINTEXT_CHANNEL` → `not_tested`

- 审计行：`A3 | EGRESS_PLAINTEXT_CHANNEL | not_tested | 0 | 0 | 0 | — | —`；
- evidence 里没有这一项；
- 也没有做过“明文外联”的实测；
- 填 `"not_tested"`，**不要填 `clear`**。

### 例 5：C2 `CRED_DEFAULT_SERVICE_LOGIN` → `found`

- 证据：`E-C2t-0001`；
- `raw_ref = etc/passwd:1`；
- 这是 Tapo C110 的静态账号发现；
- 填 `"found"`，理由写“E3 静态可登录账号”。

### 例 6：`clear` 只有在真的测过时才能填（假设示例）

假设王同学对某固件的 `EGRESS_PLAINTEXT_CHANNEL` 做了测试：

```text
materials/test_logs/A1_egress_plaintext.txt
内容：tcpdump 抓包 10 分钟，未发现明文 HTTP 外联
```

那么这一格才可以填：

```json
"EGRESS_PLAINTEXT_CHANNEL": "clear"
```

**当前项目没有这份日志，所以现在不要填 `clear`。**
这是“格式示例”，不是现有数据。

### 例 7：不一致怎么仲裁

- A：`C2 / CRED_DEFAULT_SERVICE_LOGIN = found`
- B：`C2 / CRED_DEFAULT_SERVICE_LOGIN = not_tested`
- 仲裁人打开 `evidence_sample_C2.json`，找到 `E-C2t-0001` / `etc/passwd:1`；证据存在；
- 仲裁结果：`found`；
- 记录到 `materials/annotations/arbitration.md`；
- **不要**把 A/B 原始文件都改成 `found`；kappa 用原始 A/B 算。
