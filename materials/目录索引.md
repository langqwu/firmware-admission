## 3. 命名与历史

- `decision_sample_a1/a2/a3` 是**早期样例**，当前 12 台分布看 `materials/decisions/`；
- `evidence_sample.json` 是 A3 的历史文件名，不重命名，避免破坏引用；
- `materials/firmae/unpack_C*_dlink_fail.json` 是失败证据，不是成功数据；
- `materials/decisions/A2_static.json` 是 A2 的 E3-only 对照，不是 A2 最终判定；
- `materials/decision_sample_pass_openwrt.json` 是 lab control，不得写成厂商 pass。

## 4. 清理规则

- **不要移动/重命名** `src/`、`tests/`、`materials/` 中被脚本/文档引用的路径；
- 空日志、`__pycache__`、`.pytest_cache` 可直接清理；
- `data/`、`sources/`、`.arts/` 不入库；
- `docs/03`、`docs/04` 未跟踪，是否提交由人工决定（docs 只读，不要由 Agent 改）。
